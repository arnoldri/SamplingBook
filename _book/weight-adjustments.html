8.2 Replicate weights

So we need replicate weights - generate these

In such circumstances we often create multiple sets of weights in addition to the adjusted weights. These replicate weights are what are used to estimate the standard errors, and they have the advantage that they can create standard errors for a wider range of estimators than the usual means and totals.

Jacknife weights are calculated by systematically deleting PSUs at the first stage of selection, and then scaling the weights on the remaining rows so that they still add up to the same total.

api2sc.jkdes <- as.svrepdesign(api2sc.des, type="JK1")
## Warning in as.svrepdesign.default(api2sc.des, type = "JK1"): Finite population
## corrections after first stage have been dropped

Replicate Weights are \(n/(n-1)=40/39=1.025641\) - drops one dnum out for each replicate. These need to be multiplied by the original sampling weight to get the actual weights.

Use JK1 for unstratified designs, JKn for stratified designs

svymean(~enroll, design=api2sc.jkdes)
##          mean     SE
## enroll 711.45 82.848

Better estimate of the SE.

We can poststratify these weights by the way: we poststratify each replicate weight set in addition to the probability weights themselves.

api2sc.jkdes.ps <- postStratify(api2sc.jkdes, strata=~stype, population=stype.benchmarks)
svymean(~enroll, design=api2sc.jkdes.ps)
##          mean    SE
## enroll 624.35 60.61

We get immediate reduction of the standard errors

JKn is used with stratified designs

E.g. draw a two stage cluster sample within two strata: schools which are or are not eligible for an awards programme:

set.seed(999)
apist2sc <- apipopc |>
  select.st2sc(n=40, stratumvar="awards", cfraction=0.20, clustervar="dnum")
apist2sc.des <- svydesign(id=~dnum+snum, strata=~awards, fpc=~bigN1+bigN2, 
                          data=apist2sc, nest=TRUE)
apist2sc.des.ps <- postStratify(apist2sc.des, strata=~stype, population=stype.benchmarks)

Note: we need nest=TRUE here because districts dnum do not nest within strata. I.e. it is the combination of awards and dnum that actually defines the clusters here.

There are alternative methods to Jacknife generation of replicate weights. You may hear of Bootstrap weights, and Balanced Repeated Replication. Some of these have multiple variants. We don’t need to worry about these.

8.3 Demonstration of ps SE improvement

set.seed(222)
R <- 100
sim <- t(sapply(1:R, 
              function(i) {
  ss <- apipopc |> 
    select.2sc(n=100, cfraction=0.30, mmin=2, clustervar="dnum") 
  d1 <- svydesign(ids=~dnum+snum, fpc=~bigN1+bigN2, data=ss)  
  d2 <- postStratify(d1, strata=~stype, population=stype.benchmarks)
  e1 <- ff(svymean(~api00, design=d1))
  e2 <- ff(svymean(~api00, design=d2))
  return(c(e1,e2))
}))
